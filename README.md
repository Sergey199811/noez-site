# NOEZ Site (Multipage Redesign)

Многостраничный адаптивный редизайн сайта НОЭЗ на базе структуры и смыслов текущего официального сайта.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript

## Структура проекта

```text
noez-site/
├── index.html
├── about.html
├── catalog.html
├── category-locks.html
├── category-hinges.html
├── category-handles.html
├── category-latches.html
├── category-antique.html
├── gallery.html
├── news.html
├── contacts.html
├── styles.css
├── script.js
└── README.md
```

## Что реализовано

- Полноценная многостраничная структура (11 страниц)
- Единый визуальный стиль: строгий индустриальный дизайн
- Улучшенная навигация + мобильное меню
- Хлебные крошки на всех внутренних страницах
- Категорийные страницы с профессиональными карточками товаров
- Отдельные страницы «О компании», «Галерея», «Новости», «Контакты»
- Полноценный подвал с контактами и быстрой навигацией
- Адаптивность для desktop/tablet/mobile
- Пометки для ручного дозаполнения изображений, которые не удалось автоматически выгрузить

## Запуск

```bash
python3 -m http.server 8080
```

Откройте: <http://localhost:8080>
