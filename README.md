# NOEZ Site (Multipage Redesign)

Многостраничный фронтенд-редизайн официального сайта НОЭЗ (`noez-zavod.ru`) с сохранением бизнес-логики и структуры разделов.

## Страницы

1. `index.html` — Главная
2. `about.html` — О компании
3. `catalog.html` — Каталог
4. `category-locks.html` — Категория «Замки»
5. `category-hinges.html` — Категория «Петли»
6. `category-handles.html` — Категория «Ручки»
7. `category-latches.html` — Категория «Задвижки и защёлки»
8. `category-antique.html` — Категория «Под старину»
9. `gallery.html` — Галерея
10. `news.html` — Новости
11. `contacts.html` — Контакты

## Технологии

- HTML5 (многостраничная структура)
- CSS3 (единый UI-kit, адаптив)
- Vanilla JavaScript (мобильное меню, reveal-анимации)

## Что перенесено с текущего сайта НОЭЗ

- Логика каталога и категории продукции.
- Контактные данные (телефоны, адрес, режим работы).
- Акцент на собственном производстве, дилерах/партнерах, поставках.
- Формат новостей (акции, обновления ассортимента).

## Что оставлено заглушками

- Оригинальные фото в ряде карточек (отмечены в интерфейсе, нужно дозаполнить вручную).
- Полные технические характеристики/артикулы для всего ассортимента.
- Рабочая backend-отправка формы контактов.

## Запуск

```bash
python3 -m http.server 8080
```

Открыть в браузере: `http://localhost:8080`
