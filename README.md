# NOEZ Site

Коммерческий адаптивный лендинг для производственной компании **НОЭЗ**
(Нижегородский опытно-экспериментальный завод).

## Технологии

- HTML5
- CSS3 (кастомная дизайн-система, адаптивная сетка, hover-эффекты)
- Vanilla JavaScript (мобильное меню, reveal-анимации)

## Структура проекта

```text
noez-site/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Запуск

### Вариант 1: открыть напрямую

Откройте `index.html` в браузере.

### Вариант 2: локальный сервер (рекомендуется)

```bash
python3 -m http.server 8080
```

После запуска откройте: `http://localhost:8080`

## Что реализовано

- Hero-блок с CTA
- Блок о компании
- Основные категории продукции
- Новинки продукции
- Факты/цифры о компании
- Преимущества и блок «Почему выбирают НОЭЗ»
- Витрина продукции с аккуратными заглушками
- Блок для дилеров и партнеров
- Контакты
- Подвал
- Плавные анимации появления секций
- Адаптивность для desktop/tablet/mobile
- Заглушки под будущие внутренние страницы
