# NOEZ Site (multi-page)

Многостраничный редизайн сайта НОЭЗ с сохранением структуры действующего сайта и усиленной коммерческой подачей.

## Страницы

1. `index.html` — Главная
2. `about.html` — О компании
3. `catalog.html` — Каталог
4. `category-locks.html` — Замки
5. `category-hinges.html` — Петли
6. `category-handles.html` — Ручки
7. `category-latches.html` — Задвижки и защёлки
8. `category-antique.html` — Под старину
9. `gallery.html` — Галерея
10. `news.html` — Новости
11. `contacts.html` — Контакты

## Запуск

```bash
python3 -m http.server 8080
```

Открыть: `http://localhost:8080`

## Примечание по контенту

Доступ к `https://noez-zavod.ru/` из среды разработки возвращает HTTP 403, поэтому:
- логика разделов, названия категорий и коммерческие смыслы перенесены;
- часть текстов переработана на основе уже существующей структуры проекта;
- блоки, где нужны оригинальные фото/тексты с сайта НОЭЗ, помечены как требующие ручного дозаполнения.
