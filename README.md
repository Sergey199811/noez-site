# NOEZ Site (Multi-page redesign)

Многостраничный адаптивный редизайн сайта НОЭЗ на **чистом HTML/CSS/JS**.

## Структура проекта

```text
noez-site/
├── index.html
├── about.html
├── catalog.html
├── category-locks.html
├── category-hinges.html
├── category-handles.html
├── category-bolts.html
├── category-vintage.html
├── gallery.html
├── news.html
├── contacts.html
├── styles.css
├── script.js
└── README.md
```

## Что перенесено с действующего сайта НОЭЗ

- Логика разделов: компания, каталог, новости, контакты, товарные группы.
- Товарные категории: замки, петли, ручки, задвижки/защёлки, под старину.
- Коммерческий фокус: производство, дилеры, опт, ассортимент и новинки.
- Добавлены реальные наименования из публичных материалов: `Замок накладной ЗНУ (CERBER C-1Н)`,
  `Крючок Лофт Кр-5-SL`, `Опора-держатель ОДП-75-02-SL`, `Задвижка ЗД-150-SL`,
  `Уголок декоративный УДФ 70-SL`, `Ручка сундука 160 мм`.

## Что оставлено заглушками

- Оригинальные фотографии товаров (частично недоступны для автоматического экспорта).
- Точный юридический/фактический адрес и часть контактных реквизитов — отмечены как требующие ручной проверки.
- Отдельные карточки ассортимента, где нужно связать с действующей CRM/каталогом.

## Запуск

```bash
python3 -m http.server 8080
```

Открыть: `http://localhost:8080`.
